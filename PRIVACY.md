# Приватность

## Аудио

Vosk обрабатывает звук локально. В режиме `wake_word` микрофон прослушивается для
поиска ключевой фразы, после чего открывается окно команды. В режиме `continuous`
микрофон слушается постоянно, пока прослушивание включено.

Аудиозаписи не отправляются LLM и штатно не сохраняются на диск.

## Что отправляется LLM

Только запросы, не распознанные как локальные действия, плюс ограниченная
диалоговая история и system prompt. Локальные desktop-команды, подтверждения и
аргументы действий в историю внешней LLM не добавляются.

## Хранение

- API-ключи: Windows Credential Manager через `keyring` или переменные окружения.
- Конфигурация: JSON без секретов.
- Постоянная история: выключена по умолчанию (`persist_session_history=false`).
- Логи: ротируются и проходят фильтр редактирования секретов.
- Экспорт истории: повторно редактируется перед записью.

В GUI операции «Очистить текущий экран» и «Удалить историю с диска» разделены.
Удаление с диска требует подтверждения и удаляет основной TXT и оба файла
экспорта.

Custom LLM endpoint выключен по умолчанию. При его включении API-ключ и запросы
передаются выбранному HTTPS-серверу.
