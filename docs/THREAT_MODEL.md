# Threat model

## Активы

API-ключи, пользовательский ввод, история, локальные файлы, desktop-сессия,
микрофон и возможность выполнения системных действий.

## Границы доверия

- LLM считается внешней недоверенной системой и не может выполнять действия.
- LLM не генерирует PowerShell, cmd или командную строку для исполнения.
- Desktop-действия разрешены только через Action Registry.
- Навыки выбирают только зарегистрированные `action_id` и валидированные аргументы.
- Опасные и системные действия требуют контекстного подтверждения.
- Произвольные LLM endpoints запрещены без явного opt-in.
- Секреты не хранятся в JSON и редактируются в логах/экспорте.

## Основные угрозы и меры

| Угроза | Мера |
|---|---|
| Prompt injection вызывает действие | LLM не связана с Action Registry |
| Навык запускает shell/python | skills v2 allowlist и миграция с отклонением |
| Отрицание трактуется как команда | negation-aware intent router |
| Подмена подтверждения | token, timeout и привязка к pending action |
| Утечка ключа | keyring, env priority, redacting filter |
| Утечка истории | persistence off, redacted export, отдельное удаление |
| DoS длинным вводом/очередью | лимит 8000 символов и bounded queues |
| Поздний результат старого микрофона | cancel event и generation guard |
| Подмена LLM endpoint | HTTPS/hostname validation и opt-in |

## Остаточные риски

Не завершены реальные аудиотесты, installer hardening, crash reporting,
автоматическое обновление и проверка на нескольких конфигурациях Windows.
