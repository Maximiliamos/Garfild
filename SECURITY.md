# Security policy

Поддерживаемая security-preview версия: `0.2.x`.

Не публикуйте уязвимости в открытых issue. Передайте описание владельцу
репозитория приватным каналом, указав версию, шаги воспроизведения и возможное
влияние. Не прикладывайте реальные API-ключи, пароли, историю диалогов и логи без
предварительного редактирования.

Основные гарантии:

- LLM не выполняет desktop-действия напрямую.
- Команды проходят через типизированный Action Registry и risk engine.
- Системные и необратимые действия требуют подтверждения.
- Навыки v2 могут выбирать только разрешённые `action_id`.
- API-ключи хранятся в системном keyring либо переменных окружения.
- `shell=True`, `eval`, `exec` и команды оболочки из пользовательского текста запрещены.

Security-preview не является гарантией полной защищённости. До 1.0 ещё требуются
installer, тесты на нескольких Windows-машинах, crash reporting и политика
обновлений.
